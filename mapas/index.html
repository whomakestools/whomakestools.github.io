Atalhos de teclado

    

  

  

    

      
Tab
Adicionar subtópico ao tópico selecionado

      
Enter
Adicionar tópico no mesmo nível

      
F2 ou duplo clique
Editar texto

      
H
Informar horas (sem valor próprio, o tópico soma as horas dos subtópicos)

      
Espaço
Expandir / recolher subtópicos

      
Delete
Excluir tópico (com opção de desfazer)

      
← → ↑ ↓
Navegar entre tópicos

      
Alt + ↑ ↓
Reordenar tópico

      
Arrastar tópico
Soltar sobre outro tópico para movê-lo

      
Ctrl + Z / Y
Desfazer / refazer

      
Ctrl + F
Buscar (Enter vai para o próximo resultado)

      
Ctrl + roda do mouse
Zoom (a roda sozinha move o mapa)

      
Ctrl + 0
Enquadrar o mapa inteiro

      
Esc
Cancelar edição / limpar seleção
